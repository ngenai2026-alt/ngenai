WORKSHOPS GALLERY DIRECTORY
===========================

How to use this directory:
1. Create a subfolder for each college or workshop (e.g. "COEP", "PICT", "VIT").
2. The name of the subfolder will automatically be used as the College/Workshop name on the website.
3. Place workshop images (PNG, JPG, JPEG, WEBP) inside the subfolder.
4. The website will dynamically scan this folder and display the images with filters for each college!

If you deploy to a production server where directory listings are disabled, you can run the `sync_gallery.py` script to pre-compile the list of images.
